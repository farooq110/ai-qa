The **Test cases** page lists every test in the organization, AI-drafted or manual. The header buttons open [Modules and tags](/docs/test-cases/organizing-tests), the [manual test editor](/docs/test-cases/creating-a-manual-test), and **Run selected** (see [Running tests](/docs/executions/running-tests)).

## Status tabs and filters

Tabs filter by review status — Pending review, Approved, Needs review, Rejected, Archived — with a count each. **Filters** combine and **Reset** clears them.

| Filter | Matches |
| --- | --- |
| Search | Title, capability, or route. Press `/` to focus it. |
| Project, Provider | Project, or all projects of one provider. |
| Category | The eight [categories](/docs/test-cases/creating-a-manual-test#categories). |
| Module, Tag | Your [groupings](/docs/test-cases/organizing-tests). |

## Layouts

| Layout | Use it for |
| --- | --- |
| **Lanes** (default) | Reviewing: Pending, Needs review, Approved, Rejected / archived columns. |
| **Table** | Sorting through many tests; checkboxes for bulk actions. |
| **By module** | Coverage per area, with an **Unassigned** group. |

The layout is remembered per browser. Bulk actions work in all three.

Click a test to open the [inspector](/docs/test-cases/reviewing-ai-tests).
